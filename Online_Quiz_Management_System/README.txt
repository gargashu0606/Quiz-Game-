# Online Quiz Management System

A beginner-friendly front-end demo project built using HTML, CSS and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — quiz questions, timer, navigation and score calculation

## How to run
1. Extract the ZIP file.
2. Open the `online_quiz_management_system` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Enter a student name and start the quiz.

## Notes
- This version uses JavaScript and runs entirely in the browser.
- It does not have a server, database, admin login or permanent student accounts yet.
- The questions are sample questions. You can edit the `questions` array in `script.js`.
